# Checkout

## Checkout coupon is collapsed until asked
Do not show the coupon input by default. Start with Have a coupon code? Reveal the field + Apply only after that click. Enter in the coupon field applies the code (does not submit place order). After a successful apply, show the code and a Remove action that DELETEs /checkout/coupon. Checkout re-quotes the session coupon against the current product subtotal on load and clears it when no longer valid. When `couponsAllowed` is false (Packs & Saves buy-now / `checkoutMode: pack`), hide the entire coupon block and never POST coupon. Every checkout Input/Select/DatePicker must have a placeholder. Delivery methods use radio cards with Choose one (`regular` Same day / `express` Late). Both require exactly one platform `DeliveryShift` (`time_slot_id`). Same day has no Day picker (today is wired) and only remaining today shifts (`start_time >= now`); the Same day card is never hidden, it carries an "Unavailable now" tag when no shifts remain but can still be selected: selecting it shows a message under the cards and keeps Place order disabled. Late requires a date from tomorrow through today+7 (`catalog.late_delivery_max_days`, default 7) plus any active shift. After the method cards: Same day shows **Time** only; Late shows a **Day** grid (tomorrow…today+7; selected chip is black) then **Time** (selected is blue). No DatePicker/Select dropdowns. The same-day radius notice under Delivery method is location-agnostic (nearest branch within `same_day_radius_km`, default 15 km) — never hardcode branch suburb names. Shortfall opt-in uses a Switch labeled "I accept late delivery for these items"; turning it on while Same day is selected forces Late and clears day/time. Edit cart is a small underlined text link to `/cart`. Payment methods are compact badge cards from `payment_gateway_settings` (enabled rows only) — not stacked radios and not a hardcoded COD/POS list.

## Place order stays disabled until required checkout fields
Checkout Place order is disabled until required fields are filled: name, mobile, address, city, pin lat/long, delivery and payment methods, terms, a delivery shift when the selected method `requiresSlot`, and a delivery date when `requiresDate` (Late). Do not leave the button clickable with empty required inputs.

## Cart checkout uses area polygons and late-delivery opt-in
Storefront cart quote/place use `AreaCheckoutAllocator`: AU-only pin (bounding box); inside an active `BranchArea` polygon → nearest linked branch; outside every area but still in Australia → nearest active branch. Non-AU pin → address validation error. Quote returns `requiresLateDelivery` + `shortfallLines`. When shortfalls exist, show a warning (remove from cart or accept late) and require `accept_late_delivery` before Place order; pack checkout stays branch-scoped and unchanged. Same day is never hidden for an address, but it is blocked outside the same-day radius: the quote returns `sameDayInRadius` / `sameDayRadiusKm` (`config('catalog.same_day_radius_km')`, default 15 km, straight line to the nearest active branch). With Same day selected and `sameDayInRadius === false` the checkout shows `sameDayOutOfRadiusMessage` under the Delivery method cards and keeps Place order disabled, and `PlaceOrderAction` rejects it with a `delivery_method` error (`DeliveryShiftAvailability::sameDayOutOfRadiusMessage()`). The location-agnostic same-day radius notice under the Delivery method heading shows only until a pinned address is confirmed inside the radius (no pin yet, quote pending, or outside the radius); once ``sameDayInRadius === true`` it is hidden and the address card shows the "Same-day delivery · we deliver to your area today" notice. Same day stays selectable at all times. Late delivery has no radius limit. Items on late delivery (stock shortfall) cannot go Same day (`regular`): choose Late (`express`) or remove the items. The checkout shows that error under the Delivery method cards, keeps Place order disabled, and `PlaceOrderAction` rejects it with a `delivery_method` error (`DeliveryShiftAvailability::SAME_DAY_LATE_ITEMS_MESSAGE`). Pack checkout never has late items.

## Checkout address uses AU address suggest
Delivery address uses `AddressSuggestInput` + `CheckoutMapDialog` with `countrycodes=au` (same pattern as area create / wholesale). Free-typed text is query-only; committed address + lat/lng come from a suggestion pick or map pin. Selecting a suggestion also fills city/postcode when Nominatim provides them.
